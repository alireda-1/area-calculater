# Area Calculator

A simple and interactive **Python** script that calculates the total area of a room or space based on user input.

## Features
- **User Input:** Prompts the user to enter the length and width of the space.
- **Data Conversion:** Safely handles numeric inputs with decimal points (floats).
- **Instant Result:** Calculates and prints the total area immediately in the console.

## Technologies Used
- Python 3
